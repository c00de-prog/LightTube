История LightTube хранится только в памяти сервера и очищается при его перезапуске. Выбор профиля и настройки сохраняются. Общая история для устройств домашней сети. Временные файлы удаляются при штатной остановке. Cookies выбранного браузера не удаляются.





  
Настройки

  
  

  
  
Если выключить, выбранный профиль будет использоваться по умолчанию. Переключиться можно через значок LT. Выбор общий для устройств сервера; почта в списке не отображается.

  
Рекомендуем Firefox как источник сессии YouTube. Открывать LightTube можно в Chrome и других браузерах. Используется сессия выбранного браузера на ПК. Браузер должен быть установлен, а YouTube — открыт с нужным аккаунтом. Чтение cookies Chrome/Edge на Windows может быть недоступно.

  
  
Выбирается лучший совместимый поток до лимита. Его фактическое разрешение может отличаться из-за обрезки или пропорций ролика; оно видно в диагностике. Сохранение только качества не прерывает текущий просмотр.

  

  

  
Применение к текущему видео запустит его заново с начала.

  
Выбранный браузер, профиль, качество и этот переключатель сохраняются на сервере. При смене профиля поток останавливается, а общая история LightTube очищается.
